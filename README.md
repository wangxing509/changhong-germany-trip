# 德国长虹商务出行 · 移动端出行助手

> 一键 App 在手，德国出行无忧

面向**长虹审计工作组（一行四人）2026 年 10 月 11 日 – 11 月 2 日德国商务出行**的移动端静态 Web App。
整合航班、住宿、餐饮、行程规划、工作路线、周末自助旅行、目的地天气与穿衣指数、出入境海关与安全锦囊、伴手礼推荐。

## 在线访问

GitHub Pages 静态部署，手机浏览器打开即用，支持「添加到主屏幕」作为 App 使用。

## 功能模块

| 模块 | 内容 |
| --- | --- |
| 首页 | 出发倒计时、CA431/CA432 航班卡、下一程安排、天气概览、快捷入口、补贴预算概览 |

| 锦囊 | 注意事项分册、出入境海关与安检禁忌、出发前勾选核对清单（本地保存进度）、伴手礼清单与退税要点 |

## 行程概要

- **10/11** CA431 成都天府 01:45 → 法兰克福 06:45，转往杜塞尔多夫
- **10/12–10/21** 杜塞尔多夫现场办公（含 Unna 无忧达仓库 84 km、Löhne kemena 仓库 227 km）
- **10/22–10/24** 柏林走访零售渠道（10/24 飞法兰克福）
- **10/24–10/26** 法兰克福走访零售渠道
- **10/26–10/28** 沃尔尼茨 GBL 仓库 → 因戈尔施塔特拜访 OEM 客户 IMTRON
- **10/28–10/31** 返回杜塞尔多夫现场办公
- **11/1** CA432 法兰克福 13:30 → 成都天府 11/2 06:55

> ⚠️ **时差提醒**：10/11–10/24 德国比北京晚 **6** 小时；**10/25 夏令时结束**后变为晚 **7** 小时。

## 技术实现

- 纯静态：原生 HTML + CSS + JavaScript，**零依赖、零构建工具链**，离线可用
- 数据与视图分离：所有内容位于 `data/*.json`，运行 `node build.js` 打包为 `data/app-data.js`
- 深色商务视觉语言，移动端优先（iOS 安全区适配），支持 PWA 添加到主屏
- 无追踪、无外部请求：打开页面不会向任何第三方发起网络请求

## 目录结构

```
.
├── index.html            # 应用外壳（单页，五个视图）
├── styles.css            # 设计系统与全部样式
├── app.js                # 应用逻辑（路由、渲染、交互）
├── build.js              # 数据打包脚本：data/*.json → data/app-data.js
├── manifest.json         # PWA 清单
├── assets/               # 应用图标
└── data/
    ├── itinerary.json    # 行程与航班（源文件）
    ├── budget.json       # 补贴标准与预算测算
    ├── tips.json         # 出行注意事项与核对清单
    ├── cities.json       # 各城市酒店与餐饮推荐
    ├── weather.json      # 气候、穿衣指数、行李清单
    ├── transport.json    # 交通票制与线路
    ├── weekend.json      # 周末自助出行与伴手礼
    ├── immigration.json  # 出入境、海关、安检、紧急联络
    ├── safety.json       # 安全、医疗、礼仪
    └── app-data.js       # 自动生成，勿手改
```

## 本地开发

```bash
# 修改 data/*.json 后重新打包数据
node build.js

# 本地预览（任选其一）
python -m http.server 8080
npx serve .
```

## 数据来源与免责说明

- 行程与补贴数据来自内部《德国境内行程安排》与《出差补贴标准》
- 出行提示整理自《出国注意事项-德国篇》
- 酒店、餐饮、票价、门票、签证与海关规则均经公开信息核实，**价格为参考区间**，出行前请以官方渠道实时信息为准
- 德铁（DB）车次、票价与线路施工情况变动频繁，出发前请用 DB Navigator 复核
