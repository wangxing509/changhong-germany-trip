## 行程概要

- **10/11** CA431 成都天府 01:45 → 法兰克福 06:45，转往杜塞尔多夫
- **10/12–10/21** 杜塞尔多夫现场办公（含 Unna 无忧达仓库 84 km 检查、Löhne kemena 仓库 227 km）
- **10/17–10/18** 周末：推荐科隆 / 亚琛 / 埃森工业遗产
- **10/22–10/24** 柏林走访零售渠道（Media Markt、Kaufland）
- **10/24–10/26** 法兰克福走访零售渠道
- **10/25** 周末：推荐海德堡 / 莱茵河谷；当日夏令时结束
- **10/26–10/28** 沃尔尼茨 GBL 仓库 → 因戈尔施塔特拜访 OEM 客户 IMTron
- **10/28–10/31** 返回杜塞尔多夫现场办公
- **11/1** CA432 法兰克福 13:30 → 成都天府 11/2 06:55

### 两个必须留意的关键点

1. **时差**：10/11–10/24 德国比北京晚 **6** 小时；**10/25 夏令时结束**后变为晚 **7** 小时，返程按 7 小时时差核算。
2. **客户 IMTron 就在因戈尔施塔特本地**（Imtron GmbH, Media-Saturn-Str. 1, 85053 Ingolstadt，MediaMarktSaturn 集团全资子公司）。行程表所注「156 公里 / 2 小时」系从 10/26 所在地沃尔尼茨（Wörnitz）出发的里程；10/27 当天从市区酒店前往客户处仅 10–20 分钟车程。

## 技术实现

- 纯静态：原生 HTML + CSS + JavaScript，**零依赖、零构建工具链**
- 数据与视图分离：内容全部位于 `data/*.json`，`node build.js` 打包为 `data/app-data.js`
- 深色商务视觉语言，移动端优先，适配 iOS 安全区；无位图依赖，图标与视觉均为内联 SVG / CSS 渐变
- PWA：Service Worker 网络优先 + 缓存回退，地下车库、仓库等无信号场景可正常查看
- **无追踪、无外部请求**：打开页面不会向任何第三方发起网络请求
- 支持深链：`#view=stay`、`#view=outdoor`、`#view=tips` 等可直接打开对应页面

## 目录结构

```
.
├── index.html            # 应用外壳（单页，五个视图）
├── styles.css            # 设计系统与全部样式
├── app.js                # 应用逻辑（路由、渲染、交互）
├── sw.js                 # Service Worker（离线缓存）
├── manifest.json         # PWA 清单
├── build.js              # 数据打包：data/*.json → data/app-data.js
├── assets/               # 应用图标
├── data/                 # 数据源（JSON 为唯一真相）
│   ├── itinerary.json    # 行程、航班、住宿安排
│   ├── budget.json       # 补贴标准与预算测算
│   ├── cities.json       # 四城酒店与餐饮推荐
│   ├── weather.json      # 气候、穿衣指数、行李清单、日落
│   ├── transport.json    # 德铁票制、乘车规则、主要路段
│   ├── weekend.json      # 周末自助出行与伴手礼
│   ├── immigration.json  # 出入境、海关、安检、紧急联络
│   ├── tips.json         # 出行注意事项与核对清单
│   └── app-data.js       # 自动生成，勿手改
└── scripts/
    ├── merge.mjs         # 合并调研数据（_staging → data）
    ├── validate.mjs      # 数据校验（结构与业务口径）
    ├── sun.py            # 日出日落计算（NOAA 算法）
    ├── push.mjs          # 通过 GitHub API 发布
    └── pages.mjs         # 启用 / 检查 GitHub Pages
```

## 本地开发

```bash
node build.js            # 修改 data/*.json 后重新打包
node scripts/validate.mjs # 校验数据完整性与预算口径一致性
python -m http.server 8080 # 本地预览
```

## 数据来源与免责说明

- **行程与补贴**来自内部《德国境内行程安排》与《出差补贴标准》
- **出行注意事项**整理自《出国注意事项-德国篇》，并按 2026 年新规补充
- **酒店与餐饮**：名称与地址经公开信息核实（官方酒店站点、德国黄页、官方旅游站）；**价格为参考区间，非实时报价**
- **日出日落**由 NOAA 太阳位置算法本地计算，已计入 2026 年夏令时切换，精度约 ±1 分钟
- **铁路票制**基于 DB 官方信息；施工与车次变动频繁，出行前请用 DB Navigator 复核
- **EES 与 ETIAS** 状态标注为「待核实」，出行前须以欧盟官方与德国驻华使领馆公告为准
- 本页内容仅供本次出行参考，不构成商业或法律建议
